
# 🧪 Ollama Explorer — Model Behavior & Prompting Experiments

This module explores how **system prompts**, **context grounding**, **prompt length**, and **temperature** affect responses generated by an Ollama‑hosted LLM. The goal is to build intuition around model behavior and develop practical skills for tuning LLM interactions—skills that directly support RAG development in later lessons.

---

## 📌 Overview

This project includes a script, `ollama_explorer.py`, which:

- Connects to a local Ollama server  
- Sends chat-style requests to a selected model  
- Measures response time  
- Runs four structured experiments  
- Prints results and observations for comparison  

The script uses a reusable `generate()` helper that wraps Ollama’s `/api/chat` endpoint and reports timing for each response.

---

## ⚙️ Features

- **System prompt testing**  
- **RAG-style context grounding**  
- **Response timing measurement**  
- **Temperature comparison**  
- **Error handling for server and model availability**

## 🧪 Experiments

### **Experiment 1 — System Prompt Influence**
The same question (“What is an API?”) is asked three times with different system prompts:

1. **No system prompt**  
2. **“Explain like I’m 5 years old.”**  
3. **“You are a senior software architect. Be technical and precise.”**

**Observation:**  
Responses vary significantly in tone, complexity, and vocabulary. The model adapts strongly to system-level instructions.

---

### **Experiment 2 — RAG-Style Context Grounding**
A short paragraph of context is provided. Two questions are asked:

- One **answerable** from the context  
- One **not answerable** from the context  

The system prompt instructs the model to use **only** the provided context and say *“I don’t know”* when the answer is not present.

**Observation:**  
The model correctly answers the grounded question and refuses the ungrounded one when instructed, demonstrating controlled context usage similar to RAG behavior.

---

### **Experiment 3 — Response Timing**
Three prompts of increasing length are tested:

- Short (~5 words)  
- Medium (~20 words)  
- Long (~50 words)  

Response time is measured and printed.

**Observation:**  
Longer prompts generally produce longer response times, though the exact difference varies by model size and hardware.

---

### **Experiment 4 — Temperature Effects**
The same prompt is sent twice:

- **Low temperature (0.1)** — deterministic  
- **High temperature (1.0)** — creative  

**Observation:**  
Low temperature responses are structured and predictable. High temperature responses show more creativity, variation, and expressive language.
